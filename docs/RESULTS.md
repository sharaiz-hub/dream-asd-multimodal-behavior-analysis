# Historical experimental outputs

The supplied archive included LSTM, ensemble, CAMGT and ablation CSVs, and a collection of figures. **All metrics are historical artifacts and have not been independently reproduced.** This repository must not claim a validated 96.72% accuracy or other headline performance without code, fixed splits and an auditable run manifest.

The source archive also contained subject-level records with subject IDs, ages, severity labels and ADOS values. Such CSVs have been excluded from the GitHub package pending privacy and sharing review. An aggregate, anonymized result summary can be regenerated after the underlying evaluation is verified.

See `docs/FIGURES.md` for existing plots. Figures may themselves contain historical numbers; interpret them as unverified until rerun.
