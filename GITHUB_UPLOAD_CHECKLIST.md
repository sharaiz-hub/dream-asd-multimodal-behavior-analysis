# Before uploading

- [ ] Set repository to **Private**.
- [ ] Verify permission to store the supplied figures and result artifacts on GitHub.
- [ ] Confirm that excluded subject-level files are not uploaded in Git history.
- [ ] Check any remaining figures/CSV for sensitive content and inadvertent identifiers.
- [ ] Obtain rights for the dataset and code before wider distribution.
- [ ] Restore and audit missing source code before describing the repository as reproducible.
- [ ] Do not add an unverified LICENSE or publish unverified performance claims.
